# HealthcareEDI834 — Healthcare Enrollment Workbench

**[Open the Live Website](https://vinaykumarvuppala.github.io/HealthcareEDI834/#state)** · **[View the GitHub Repository](https://github.com/Vinaykumarvuppala/HealthcareEDI834)**

A browser-based, synthetic-data learning and testing workbench for Medicaid enrollment, EDI 834 processing, payer-system reconciliation, and AWS/Azure ETL examples. Designed for business analysts, enrollment specialists, QA engineers, developers, and data engineers.

## What you can explore

- Select Medicaid states and training program scenarios.
- Generate synthetic EDI 834 files and inspect member/coverage records.
- Explore validation, before/after comparisons, reconciliation and QA test data.
- Learn synthetic ZIP → EDI → JSON workflows and AWS/Azure ETL patterns.
- Review payer-neutral models without relying on proprietary payer database tables or columns.

> **Training use only.** This public GitHub Pages application is not certified for real Medicaid submissions, full X12 compliance validation, or processing protected health information (PHI). Use fictional member data.
